# LoanDesk – Home Loan Application Management API

LoanDesk is a backend REST API designed to manage customer
records and home loan applications.

## Features

- Register and retrieve customers
- Create and track home loan applications
- Calculate monthly loan EMIs
- Validate loan amounts and customer details
- Update loan application statuses
- Enforce valid loan status transitions
- Prevent duplicate customer email registrations
- Automated API testing

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- Pytest
